# 키움 REST API 픽스처

계약 테스트가 읽는 **실제 응답**이다(헌법 원칙 III). `backend/scripts/capture_kiwoom_fixtures.py`로
2026-10-02에 받았다(006 T005). 공식 문서의 응답 예시는 자리 표시용이라 쓰지 않는다.

| 파일 | 내용 | 출처 |
|------|------|------|
| `KOSPI_p01.json` 등 5개 | 단위별 전 목록(한 쪽) | 실제 응답 |
| `*.meta.json` | HTTP 상태, `cont-yn`, `next-key` | 실제 응답 헤더 |
| `error_auth_token.json` | 틀린 앱 키로 토큰 발급 | 실제 응답(가짜 키 사용) |
| `error_invalid_token.json` | 무효 토큰으로 목록 조회 | 실제 응답(가짜 토큰 사용) |
| `error_rate_limit.json` | 호출 한도 초과(`1700`) | **손으로 만듦** — 일부러 일으키지 않는다 |

- **토큰 발급 성공 응답과 요청·응답 헤더는 저장하지 않았다** — 접근 토큰과 인증 헤더가 섞인다(FR-061).
- 짧게 온 목록(축소 검사)과 여러 쪽에 걸친 응답은 테스트가 이 실제 목록을 잘라 만든다.
- **저장소가 비공개라 전체 목록을 커밋한다**(research R6-15). 공개로 바꾸기 전에 검증에 필요한 행으로 줄인다.
