# Quickstart: 가상자산 투자 시뮬레이션 — 검증 안내

**Feature**: `007-crypto-investment-simulation` | 근거: [contracts/rest-api.md](./contracts/rest-api.md),
[contracts/ui-wireframes.md](./contracts/ui-wireframes.md), [data-model.md](./data-model.md)

기능이 처음부터 끝까지 동작함을 보이는 시나리오다. 구현 코드는 tasks와 구현 단계의 몫이다.

## 준비

```bash
cd backend && .venv/bin/python -m alembic upgrade head      # 가상자산 테이블 11개 (data-model)
./be-start.sh && ./fe-start.sh                                # 백엔드 8080(단일 워커), 프론트엔드 3030
```

- `.env`에 출처 설정이 있다 — `INVESTING_USER_AGENT`(브라우저형 문자열), 간격·재시도(research R7-1). 로그인 정보는 없다
- USD 환율(외환 001~004)을 받아 둔 상태면 원화 원금 실행이 바로 된다. 없으면 환율 수집 안내(202)가 먼저 나온다
- **개발 서버를 띄운 채 통합 테스트를 돌리지 않는다** — 테스트는 `assetreplay_test` DB를 쓰지만 같은 규약을 지킨다(CLAUDE.md)

## 자동 검사

```bash
cd backend && .venv/bin/python -m pytest -q --cov=src        # 네트워크 없이 통과(헌법 원칙 III), 커버리지 80%+
cd backend && .venv/bin/python -m mypy src && .venv/bin/python -m ruff check src tests
cd frontend && npm test && npx tsc --noEmit && npx eslint .
```

계약 테스트는 출처의 **실제 응답을 저장한 픽스처**로 한다 — 목록 영문·한국어 첫 쪽과 마지막 쪽, BTC 일봉 청크, 오늘 일봉이 든 응답,
거래량 빈 값(BTC 2011-06), 아주 작은 가격(SHIB), 일봉 없는 코인(Doge Killer), 차단 응답(403, 본문 `403`).
