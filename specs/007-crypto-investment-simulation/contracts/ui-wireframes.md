# UI Wireframes: 가상자산 투자 시뮬레이션

**Feature**: `007-crypto-investment-simulation` | 근거: [rest-api.md](./rest-api.md), [research.md](../research.md) R7-12

화면은 주식(`/stocks`)을 본뜬다. 아래는 **주식과 다른 곳**만 그린다 — 나머지(성과 추이 차트, 이력, 이력 비교, 수집 안내의 진행 줄,
환율 수집 안내)는 005·006과 같다.

---

## C1. 메뉴와 화면 (FR-001)

```
 AssetReplay              │ 가상자산 투자 시뮬레이션
 ─────────────            │ 매수 후 보유한 투자 성과 (일봉 기준: UTC 하루)
  대시보드   준비중        │
  외환                    │ ┌───────────────────────────────────────────────────────────────┐
▶ 가상자산                │ │ 코인  [ 이름·심볼·한글·초성으로 검색 (예: ㅂㅌㅋㅇ, BTC)       ] │
  주식                    │ │       비트코인 Bitcoin  BTC · USD  #1                           │
  예금       준비중        │ │ 시작일 « ‹ [2020-01-01] › »   투자 원금 [ 10,000,000 ] [KRW ▾]   │
  부동산     준비중        │ │                                             [ 시뮬레이션 ]       │
  투자 비교  준비중        │ └───────────────────────────────────────────────────────────────┘
  설정                    │
```

- 메뉴 순서를 헌법 원칙 IX대로 고친다 — 외환 → **가상자산** → 주식(지금은 주식이 앞이다, research R7-12)
- 배당 재투자 칸이 **없다**
- 화면 머리에 일봉 기준(UTC 하루)을 밝힌다(FR-021)
- 시작일 상한은 **UTC 어제**다(FR-009, FR-022)
- 고른 코인 표시: 한글 이름(있으면)·영문 이름·심볼·시세 통화, 순위는 **있을 때만**(`#1`) — 이력에서 다시 실행한 코인처럼 순위를 모르면 빈자리
  없이 뺀다(FR-004)

## C2. 코인 검색 (FR-003~FR-006)

```
 코인 [ ㅂㅌ                                     ]
      ┌──────────────────────────────────────────────────────────┐
      │ 목록 기준 10-03 18:40                                      │
      │ ▸ 비트코인  Bitcoin                       BTC · USD  #1    │
      │   비트쉐어  BitShares                     BTS · USD  #1355 │
      └──────────────────────────────────────────────────────────┘

 코인 [ max                                      ]
      │ ▸ MAX Exchange Token                      MAX · USD  #763  │
      │   Giggle Mascot                           MAX · USD  #1358 │
      │   Mastercard tokenized stock (xStock)     MAX · USD  #2757 │
      │   MAX                                     MAX · USD  #3084 │
      │   MaxCoin                                 MAX · USD  #5359 │
```

(예시는 2026-10-03 출처 목록의 실제 값이다. 한글 이름은 한국어 판이 준 12개뿐이다 — research R7-5)

- 한 줄: **한글 이름**(있으면) · 영문 이름 · 심볼 · 시세 통화 · 순위(`#n`). 같은 심볼은 이름과 순위로 구별한다(FR-004)
- 엔터 = 맨 위, 한글 조합 중 엔터·방향키는 무시(006 FR-056·버그 `search-enter-ime`과 같다)
- "목록에서 빠짐"은 글자로 쓴다(색만으로 전달하지 않는다)
- 목록 상태 줄: 기준 시각. 갱신 중이면 "목록을 새로 받는 중 — 이전 목록으로 찾습니다", 실패면 사유와 이전 목록 기준 시각(FR-005)
- 목록을 받은 적이 없으면 "코인 목록을 처음 받는 중입니다 · 영문 12쪽 받음" — 결과 없음과 구별한다. 진행은 SSE로 실시간 갱신한다
  (FR-005b). 이전 목록이 있으면 "목록을 새로 받는 중 · 한국어 8/37쪽 — 이전 목록으로 찾습니다"
- 진행 표시 규칙(FR-005b): 전체 쪽 수를 모르면 "<판> n쪽 받음", 알면 "<판> n/m쪽". 판이 바뀌면 0쪽부터 다시 센다. 갱신 줄이 시작하기
  전에는 쪽 수 없이 "코인 목록을 처음 받는 중입니다". 처음 받을 때 실측 영문 36쪽 → 한국어 37쪽, 약 112초
- 목록 갱신 실패 사유(FR-020) — 이전 목록으로 계속 찾는다:

  | 종류 | 문구 |
  |------|------|
  | `blocked` | 시세 출처가 접근을 막았습니다. |
  | `format` | 출처의 응답 형식이 예상과 다릅니다. |
  | `network` | 출처에 연결하지 못했습니다. |
  | `shrunk` | 받은 목록이 이전보다 크게 줄어 교체하지 않았습니다. |

- 한국어 판만 실패하면 "한글 이름을 새로 받지 못했습니다 — 저장된 한글 이름과 영문 이름·심볼로 찾습니다"(FR-006)

## C3. 성과 보드 (FR-042, FR-042a)

```
┌──────────────────────┬──────────────────────┬──────────────────────┐
│ 투자 원금             │ 투자 수익             │ 수익률                │
│ $10,000 (₩11,578,000)│ ₩125,749,793         │ +1086.12%            │
├──────────────────────┴──────────────────────┴──────────────────────┤
│ 2026-10-02 기준 · KRW 기준 · 매수일 2020-01-01 · 수수료 0.1%          │
└────────────────────────────────────────────────────────────────────┘
```

- 006의 `PerformanceBoard`를 그대로 쓴다(투자 원금 기호·KRW 괄호, 수익 ₩, KRW 기준). 원화 원금이면 환전 줄이 붙는다
- 기준 줄에 **매수일과 적용 수수료율을 늘 보인다**(FR-042) — 매수일은 시작일이 아니라 시작 월의 첫 일봉이다(FR-025)
- 기호는 **숫자 앞**이다(반복 2026-10-04, FR-042a) — `₩10,000,000`, `$10,000 (₩11,578,000)`, 손실 `-₩5,446`, 모르는 통화 `GBP 1,000`.
  주식 화면의 보드도 같다(006 FR-054의 "숫자 뒤"를 대체)
- 시작 월 1일 일봉이 결측이면 그 달의 첫 일봉이 매수일로 보인다(FR-030)

## C4. 일자별 투자 성과 표 (FR-037~FR-041)

```
 날짜         시가      구매 수량    매매 수수료  보유 수량    예수금  투자금      잔고                  투자 수익     수익율     환율
              (USD)                 (USD)                    (USD)   (KRW)       (USD · KRW)           (KRW)        (KRW 기준)
 2026-10-01   83,553.9     0          —          1.19842631  0.00   10,000,000  100,132.61 (135,749,793) 125,749,793 +1257.50%  1,355.70
 2021-03-02◇  49,612.3     0          —          1.19842631  0.00   10,000,000   59,456.10 (67,250,123)  57,250,123  +572.50%   1,131.10
 2020-01-01   7,196.39  1.19842631   8.62        1.19842631  0.00   10,000,000    8,624.07 (9,973,000)   -27,000     -0.27%    1,156.40
```

- 열: 날짜, 시가, 구매 수량, 매매 수수료, 보유 수량, 예수금, 투자금, 잔고, 투자 수익, 수익율, 환율(시세 통화가 KRW가 아니면). **배당 관련
  열이 없다**(FR-037)
- 통화는 열 이름 아래 줄(006 R6-26). 잔고 괄호는 KRW
- **`◇` = 그 달 1일 일봉이 출처에 없어 다른 날이 그 달의 행이다** — 글자 설명(`title`·`aria-label`: "2021-03-01 일봉이 없어 03-02 일봉을
  썼습니다")을 함께 둔다(FR-030, 색·기호만으로 전달하지 않는다)
- 수량은 소수 8자리. 시가는 **유효 숫자를 잃지 않게** — 1 이상이면 소수 2자리, 1 미만이면 유효 숫자 4자리 이상(`0.00000579`). `0`·`0.00`으로
  보이면 안 된다(FR-040, SC-009)
- 열 폭은 내용에 맞추고 1440px에서 모든 열이 보인다(006 FR-069·버그 `table-column-width`와 같다)

## C5. 차트의 결측과 축 (FR-043, FR-043a, FR-046a)

```
 잔고(KRW) ───────╮      ╭─────────     범례: ─ 잔고 (KRW)  ╌ 수익률 (%)  ┆ 결측 1구간
                  ╰ ┆ ┆ ╯
                   (2021-03-01 결측 — 선이 끊긴다)
```

- `source_missing` 구간에서 선을 끊고, 범례에 "결측 N구간"을 쓴다. 주식의 휴장(잇는다)과 다르다(FR-023)
- 축 눈금은 천 단위 쉼표(반복 2026-10-04, FR-043a) — 왼쪽 잔고(KRW)는 소수점 없이, 오른쪽 수익률(%)은 소수 2자리. 끊긴 구간이 있어도
  모든 구간이 같은 형식이다. 툴팁·범례는 그대로. 주식 화면의 차트도 같다
- 이력 비교 차트의 수익률 축도 같은 형식이다(반복 2026-10-04 #2, FR-046a) — `1,881.47`, `-400.00`

## C6. 설정 — 가상자산 거래 수수료율 (FR-032)

```
 주식
   매매 수수료        [ 0.015 ] %
   배당 소득세 (국내) [ 15.4  ] %
   배당 소득세 (해외) [ 15    ] %
 가상자산
   거래 수수료        [ 0.1   ] %   (기본값)
                                    [ 저장 ]
```

- 주식 설정과 **따로** 저장한다. 0 이상 100 미만이 아니면 저장하지 않고 사유를 보인다
- 기본값과 다르면 "기본값으로" 수단(006과 같다)

## C7. 수집 안내와 실패 (FR-013, FR-020)

```
 ⟳ 비트코인의 시세를 받고 있습니다 | 1,460 / 2,467일 | 받을 구간: 2020-01-01 ~ 2026-10-02
 ⚠ 시세 출처가 접근을 막았습니다. 이미 받은 구간만으로는 결과를 낼 수 없습니다 — 잠시 뒤 다시 실행하세요.
```

- 진행 줄은 006 `CollectingNotice`와 같다(받은 날 / 받을 날)
- 실패 사유는 종류마다 다르게 말하고 할 일을 함께 쓴다(FR-020):

  | 종류 | 문구 | 할 일 |
  |------|------|-------|
  | `blocked` | 시세 출처가 접근을 막았습니다. 이미 받은 구간만으로는 결과를 낼 수 없습니다 — 잠시 뒤 다시 실행하세요. | 기다린다 |
  | `format` | 시세 출처의 응답 형식이 바뀌었습니다. 이미 받은 구간만으로는 결과를 낼 수 없습니다 — 어댑터를 고쳐야 합니다. | 코드 수정 |
  | `network` | 시세 출처에 연결하지 못했습니다. 다시 실행하면 이어서 받습니다. | 다시 실행 |
  | `empty` | 출처에 이 코인의 시세가 없습니다. | 다른 코인 |

  `empty`는 수집이 끝났는데 그 코인의 일봉이 하나도 없을 때다 — 일부 구간만 비면 결측·끊김이다

## 접근성

- 한글 이름이 없는 코인은 영문 이름이 맨 앞이다 — 빈 칸을 두지 않는다
- 목록 상태 줄과 수집 안내는 알림 역할(`role="status"`)이고, 실패·막힘은 경고 역할(`role="alert"`)이다(005·006과 같다)
- 수집 진행 막대는 값과 범위를 가진 진행 표시다(`role="progressbar"`, `aria-valuenow`·`aria-valuemin`·`aria-valuemax`, 006 `CollectingNotice`)
- 표의 `◇`(1일 결측)와 `📅`(환율 고시 없음)는 글자 설명이 있는 이미지 역할(`role="img"` + `aria-label`)이다 — "2021-03-01 일봉이 없어 03-02
  일봉을 썼습니다"처럼
- "목록에서 빠짐"은 색이 아니라 글자로 쓴다. 순위는 `#n` 글자다
- 손익은 색만으로 구별하지 않고 부호와 함께 쓴다(`-₩5,446`, `-90.08%`)
- 검색 결과는 목록 역할(`listbox`·`option`, 고른 항목은 `aria-selected`), 이력의 고르기·다시 실행·삭제는 코인 이름이 든 `aria-label`을 가진다
