# UI 와이어프레임 — 006

**Feature**: `006-stock-simulation-enhancements` | **Date**: 2026-10-02

005의 화면(`/stocks`, `specs/005-stock-investment-simulation/contracts/ui-wireframes.md`)에서 **입력
영역과 수집 안내만** 바뀐다. 표·보드·차트·이력·비교는 005 그대로다.

---

## W1. 시작일

```
  시작일
  [«] [‹]  [ 2020-01-01 ]  [›] [»]
   1년 1달                  1달 1년
```

- 처음 들어오면 `2020-01-01`(FR-001). 날짜 칸에 직접 입력할 수 있다(FR-002).
- `‹ ›` 한 달, `« »` 1년. 없는 날짜는 그 달의 마지막 날로 맞춘다(FR-003).
- 어제가 속한 달을 넘어가는 `› »`는 누를 수 없다. 직접 입력한 미래 날짜는 칸 아래에 사유를 보이고
  실행을 막는다(FR-004).
- 종목을 바꿔도 시작일은 그대로다(FR-006).

### W1a. 시작일이 상장일보다 이를 때 (FR-005)

```
  [«] [‹]  [ 2020-01-01 ]  [›] [»]
  ⚠ 이 종목은 2021-05-03에 상장했습니다. 그 이전은 계산할 수 없습니다.
     [ 2021-05로 옮기기 ]
```

- 검색 결과의 `listedOn`으로 **실행 전에** 보인다. 옮기기 버튼을 눌러야 바뀐다 — 몰래 옮기지 않는다.
- 하한보다 이른 동안에는 **실행 버튼을 막는다** — 서버가 거절할 요청이다(구현 단계 결정, T061).
- 실행 뒤 `before_listing`(`basis: price_start`)이 오면 같은 모양으로 `startableFrom`을 보인다(FR-005a).

## W2. 종목 검색

```
  종목  [ ㅅㅅㅈㅈ                                   ]
  ┌───────────────────────────────────────────────────────────────┐
  │ 국내·미국                                                       │
  │  삼성전자(005930)                               KRX · KRW       │  ← 종목명(코드)
  │  삼성전자우(005935)  우선주                     KRX · KRW       │
  │  … 결과가 더 있습니다. 검색어를 더 입력하세요.                    │  ← FR-024
  │ ─────────────────────────────────────────────────────────────── │
  │  목록 기준  KOSPI 10-02 09:05 · KOSDAQ 10-02 09:05 · 미국 갱신 중 │  ← FR-029
  │ ═══════════════════════════════════════════════════════════════ │
  │ 일본                                                            │
  │  (검색 중…)                                                      │  ← FR-027
  └───────────────────────────────────────────────────────────────┘

  고른 뒤 (칸 아래):
  삼성전자(005930) KRX · KRW
```

- **두 영역을 따로 채운다.** 국내·미국은 로컬 검색으로 곧바로, 일본은 외부 검색이 오는 대로(FR-027).
  일본 검색의 실패는 일본 영역에만 표시한다(SC-015).
- 결과마다 시장·통화(005 FR-002b), 우선주·클래스 구별, ETF·리츠 표시, "목록에서 빠짐" 표시(FR-025).
- **종목명(코드)** — 국내 6자리, 미국 티커(`애플(AAPL)`, `버크셔 해서웨이 B(BRK-B)`), 일본 4자리
  (`토요타자동차(7203)`). 코드는 이름 옆에 한 번만 쓰고 오른쪽 칸은 시장·통화만. 고른 종목 표시도 같은 형식이다
  (FR-025, 반복 2026-10-03, research R6-20).
- **늦게 온 이전 결과는 그리지 않는다**(FR-029a).
- 방향키로 고른 항목 없이 **엔터** → 맨 위 결과(국내·미국 첫 줄, 없으면 일본 첫 줄)를 고른다(FR-056, 반복 2026-10-03 #3).

### W2a. 목록이 없을 때 (FR-028, FR-028a)

```
  │ 국내·미국                                                       │
  │  ⓘ 국내·미국 종목 목록을 받지 못했습니다.                         │
  │     키움증권 인증 정보가 설정되지 않았습니다.                     │
  │     .env에 KIWOOM_APP_KEY·KIWOOM_APP_SECRET을 넣고 백엔드를       │
  │     다시 시작하세요.                                             │
```

- "결과 없음"이라고 말하지 않는다(SC-006). **할 일**을 말한다(FR-028a).
- 사유별 문구: 인증 정보 미설정 / 인증 실패 / 받는 중(기다리기) / 받기 실패(잠시 뒤 다시).

## W3. 원금 통화 (FR-050~050d)

```
  투자 원금 [   1,000,000 ]  통화 [ KRW ▾ ]       ← 국내 종목: KRW만
                                   [ KRW | USD ]   ← 미국 종목
                                   [ KRW | JPY ]   ← 일본 종목
```

- 선택지는 `KRW`와 종목 통화뿐이다. `EUR`은 없다.
- 원금 칸은 정수부를 **3자리마다 쉼표**로 보인다(`10,000,000`, `1,234.5`). 쉼표는 표시일 뿐 요청·이력에는 쉼표 없는
  값이 간다. 이 그림은 처음부터 쉼표를 그렸지만 구현이 빠뜨렸다(FR-053, 반복 2026-10-03).
- 종목을 바꿔 지금 통화가 허용되지 않으면 **값을 바꾸지 않고** 다시 고르게 한다(FR-050b).

```
  통화 [ USD ▾ ]  ⚠ 국내 종목은 원화 원금만 고를 수 있습니다. 통화를 다시 고르세요.
  [ 시뮬레이션 ] (비활성)
```

- 이력의 막힌 조합 항목은 목록에 그대로 있고, 다시 실행·비교에 고르면 사유를 보인다(FR-050c).

## W4. 수집 중 (FR-043~046)

```
  ┌────────────────────────────────────────────────────────┐
  │  토요타자동차의 시세를 받고 있습니다                      │
  │  ████████████░░░░░░░░░  730 / 2,467일                    │  ← 받은 날 / 받을 날
  │                                                        │
  │  JPY 환율: USD 수집이 끝나면 시작합니다                   │  ← waiting (FR-046)
  │                                                        │
  │  둘 다 끝나면 결과가 표시됩니다.                          │  ← FR-045
  └────────────────────────────────────────────────────────┘
```

- 005의 수집 안내에 **환율 줄**을 더한다. `fx.state`별 문구: 대기열에 넣음 / 받는 중 / 다른 통화
  수집 대기.
- 부분 결과를 보이지 않는다(005 FR-049).
- 진행 줄은 **받은 날 / 받을 날**(달력 일수, 3자리 쉼표)이고 막대도 일수 기준이다. 출처에 2년치씩 요청하므로
  숫자는 구간마다 늘어난다. 진행이 도착하기 전에만 "시작하는 중…"을 보인다 — 진행은 실시간으로 도착해야 한다
  (FR-045a, 반복 2026-10-03, research R6-19).

### W4a. 수집으로 채울 수 없는 구간 (FR-043a)

```
  ⚠ 1971-01-04 이전의 JPY 환율은 출처에 없습니다.            ← before_first_quote
     시작일을 1971-01 이후로 옮기세요.   [ 1971-01로 옮기기 ]

  ⚠ JPY 환율 수집 범위가 2000-01-01부터로 설정되어 있습니다.  ← before_probe_start
     설정(ECOS_PROBE_START_JPY)을 바꾸면 받을 수 있습니다.
     또는 시작일을 2000-01 이후로 옮기세요.  [ 2000-01로 옮기기 ]
```

- 두 문구를 섞지 않는다. 아래 경우는 **풀 수 있는 제약**이라 할 일(설정 변경)을 함께 말한다.

```
  ┌──────────────────────┬──────────────────────┬──────────────────────┐
  │ 투자 원금             │ 투자 수익             │ 수익률                │
```

## W6. 표 — 바뀌는 점 (FR-057, FR-058, FR-059) — 반복 2026-10-03 #3

```
  날짜          시가    주당배당  배당율  배당소득세  구매  매매수수료  보유  예수금 …
  2026-09-28◆  …       1.823    0.31%   4,212           0                12  …      ← 배당락
  2026-09-30⟳  …                                   1      52            13  …      ← 재투자
  2026-10-01   …                                   0                    13  …      ← 월 첫 거래일
```

- 주당 배당금은 **소수 3자리**(종목 통화 값, 원금 통화 규칙을 쓰지 않는다), 배당율은 **소수 2자리**.
- **배당 소득세**는 배당락 행에만, **매매 수수료**는 매수가 있는 행(초기 매수·재투자)에만 있다. 금액은 원금 통화다.
- 재투자는 배당락 뒤 2번째 거래일의 **"재투자" 행**이다. 색만으로 구별하지 않고 글자·기호로도 표시한다.

## 접근성

- 시작일 이동 버튼은 "1년 전", "한 달 전"처럼 보조 기술에 읽히는 이름을 갖는다.
- 목록 상태 줄과 수집 안내는 알림 역할이다(005와 같다).
- "목록에서 빠짐"·우선주·ETF 표시는 색만으로 전달하지 않는다. 글자로 쓴다.
