**Feature**: `009-real-estate-investment-simulation` | 근거: [contracts/rest-api.md](./contracts/rest-api.md),
[contracts/ui-wireframes.md](./contracts/ui-wireframes.md), [data-model.md](./data-model.md), [research.md](./research.md)

기능이 처음부터 끝까지 동작함을 보이는 시나리오다. 구현 코드는 tasks와 구현 단계의 몫이다.

## 준비

**구현 전에 사용자가 할 일 — 공공데이터포털 활용신청**(research R9-1, R9-3). 같은 계정이라 인증키(`DATA_API_KEY`)는 그대로다. 2026-10-05
실측에서 지금 키는 기본 실거래 자료에만 등록되어 있었다.

| # | 자료 | 엔드포인트 | 쓰는 곳 |

| ① | 국토교통부 아파트 매매 실거래가 **상세 자료** | `/1613000/RTMSDataSvcAptTradeDev/getRTMSDataSvcAptTradeDev` | 거래(단지 일련번호·법정동 코드·지번) |

| ③ | 국토교통부 공동주택 단지 목록 | `/1613000/AptListService4/getLegaldongAptList4` | 법정동의 단지 목록 |

신청이 승인되면(자동 승인이 보통이다 — 반영에 1~2시간 걸릴 수 있다) T001이 네 자료의 실제 응답을 픽스처로 받는다. 등록 전 응답은 HTTP 403 +
게이트웨이 사유 30이다.

```bash
cd backend && .venv/bin/python -m alembic upgrade head      # 부동산 테이블 10개 (data-model)
./be-start.sh && ./fe-start.sh                                # 백엔드 8080(단일 워커), 프론트엔드 3030
```

- `.env`의 `DATA_API_KEY`를 쓴다. 키 값을 출력하거나 셸 인자로 넘기지 않는다. 새 설정(모두 선택 — 없으면 기본값): `DATA_API_MAX_CONCURRENT`(3),
  `DATA_API_DAILY_LIMIT_TRADE`(9000)·`_KAPT`(4500)·`_REGION`(9000), `DATA_API_RETRY_MAX_ATTEMPTS`(4)·`DATA_API_RETRY_BASE_DELAY_MS`(1000),
  `APT_TRADE_PROBE_START`(**코드 기본값 없음** — `.env.example`의 `2005-01`을 옮긴다. 없으면 실거래 수집이 사유와 함께 멈춘다), `APT_TRADE_PROVISIONAL_MONTHS`(12), `APT_TRADE_DAILY_RECHECK_MONTHS`(3), `APT_LIST_REFRESH_DAYS`(30)
- 처음 고르는 시·군·구는 전체 이력(약 280회)을 받는다 — 하루 한도(9,000회)로 30곳 남짓이다(research R9-5)
- **개발 서버를 띄운 채 통합 테스트를 돌리지 않는다**(CLAUDE.md)

## 자동 검사

```bash
cd backend && .venv/bin/python -m pytest -q --cov=src        # 네트워크 없이 통과(헌법 원칙 III), 커버리지 80%+
cd backend && .venv/bin/python -m mypy src && .venv/bin/python -m ruff check --no-cache src tests
cd frontend && npm test && npx tsc --noEmit && npx eslint .
```

계약 테스트는 공공데이터포털의 **실제 응답을 저장한 픽스처**로 한다(research R9-9) — 상세 실거래(송파구 2020-01~2023-09, 해제가 있는 달,
2쪽짜리 달), 단지 목록·기본 정보(가락동), 법정동코드(서울특별시 송파구 일부), 게이트웨이 오류(사유 30), 빈 결과. 픽스처에 인증키가 없는지
자동으로 검사한다(응답 본문만 — 요청 URL을 저장하지 않는다).

참조값 단위 테스트:

- **헬리오시티 스프레드시트**(SC-003) — 2020-01~2023-09 45개월 × 평형 5구분 = 225칸의 건수·평균이 **해제를 넣은 계산**으로 모두 같다. 해제를
  뺀 기대값은 같은 픽스처에서 따로 손계산해 둔다(그 기간 해제 27건 — research R9-2)
- **시세 창**(SC-004) — 1·3·6·12·24·36개월, 시세 없음, 잠정 달 포함 사례
- **세금·수수료**(SC-005) — 취득세(85㎡ 이하·초과, 가액 구간, 2013-08-28·2020-01 전후), 중개 보수(2015-04·2021-10-19 전후 구간), 재산세(분할·
  일괄, 1세대 1주택 특례 전후), 종부세(부부 5:5, 공제 이하 0원, 2021·2022·2023) — 10원 단위까지
