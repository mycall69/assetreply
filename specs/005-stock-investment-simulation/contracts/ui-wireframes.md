# Contract: UI 와이어프레임 — 005

**Feature**: 005-stock-investment-simulation | **Date**: 2026-09-27

와이어프레임은 **배치와 정보의 계층**을 정한다. 색·여백·타이포그래피는 구현에서 정한다.

001~004가 세운 것을 잇는다 — 전역 셸의 자산군 메뉴, 표의 스크롤 탐색, 차트의 결측
렌더링, 분절 컨트롤의 모양.

---

## W1. 화면 구성

```
┌──────────────────────────────────────────────────────────────────────────┐
│  주식 투자 시뮬레이션                                                     │
│                                                                          │
│  ┌────────────────────────────────────────────────────────────────────┐ │
│  │ 종목  [ 삼성전자                          🔍 ]                      │ │
│  │       ┌──────────────────────────────────────────┐                 │ │
│  │       │ 삼성전자      KRX · KRW                   │ ← 검색 결과     │ │
│  │       │ 삼성전자우    KRX · KRW                   │                 │ │
│  │       └──────────────────────────────────────────┘                 │ │
│  │ 시작일 [ 2021-08-01 ]   원금 [ 86,997 ] [ KRW ▾ ]  ☑ 배당 재투자   │ │
│  │                                              [ 시뮬레이션 ]         │ │
│  └────────────────────────────────────────────────────────────────────┘ │
│                                                                          │
│  ┌──────────────┬──────────────┬──────────────┐  ← 성과 보드 (W2)      │
│  │ 투자 원금     │ 투자 수익     │ 수익률        │                        │
│  │ 86,997원     │ +120,777원   │ +138.83%     │                        │
│  └──────────────┴──────────────┴──────────────┘                        │
│                                                                          │
│  [ 잔고·수익률 차트 ]                                    ← W3            │
│                                                                          │
│  일자별 투자 성과                                        ← W4            │
│  ─────────────────────────────────────────────────────────────────────  │
│                                                                          │
│  최근 시뮬레이션                                          ← W5            │
└──────────────────────────────────────────────────────────────────────────┘
```

**검색 결과에 시장과 통화를 함께 보인다**(FR-002b). 같은 이름이 여러 시장에 있고, 통화가
다르면 환전 여부와 수익률 기준이 달라진다.

**코드를 직접 입력하는 칸을 두지 않는다**(FR-002a). 입력 칸은 검색어를 받는 자리이고,
확정은 목록에서 고르는 것으로만 이루어진다.

## W2. 성과 보드

```
┌──────────────┬──────────────┬──────────────┐
│ 투자 원금     │ 투자 수익     │ 수익률        │
│ 86,997원     │ +120,777원   │ +138.83%     │
│              │              │              │
│ 2021-08-02 ~ 2024-08-01 기준                │
└──────────────┴──────────────┴──────────────┘
```

**기준 구간을 함께 쓴다.** 계산의 마지막 날이 오늘이 아니면(상장폐지·거래정지) 그 사실이
여기서 드러나야 한다 (FR-014b).

```
⚠ 2024-08-01 이후 시세가 없습니다. 그 날짜까지의 결과입니다.
```

알리지 않으면 사용자는 보드를 **오늘까지의 결과**로 읽는다. 상장폐지는 대개 큰 손실인데
화면에는 폐지 직전의 수익률이 남는다.

**보드와 표 마지막 행의 수치가 같아야 한다**(FR-032). 어긋나면 사용자는 어느 쪽이 맞는지
알 수 없다.

### 외화 종목일 때

```
환전  2021-08-02 현금 살 때 1,305.42원 (스프레드 10% 적용)
      ※ 수익률은 KRW 기준입니다
```

**기준 통화를 밝힌다**(FR-041, SC-019). 밝히지 않으면 사용자가 어느 쪽을 보고 있는지
모른다.

투자 시작일에 고시가 없어 다른 날짜의 환율을 썼다면 그 날짜가 보인다 (FR-022).

## W3. 차트

잔고와 수익률을 함께 본다. 축이 다르므로 한 축에 겹치지 않는다.

```
 잔고                                                     수익률
 250,000┤                                    ╱‾‾╲        ┤ 200%
        │                              ╱‾‾‾‾╯    ╲       │
 150,000┤                    ╱‾‾‾╲╱‾‾‾╯           ╲      ┤ 100%
        │          ╱‾‾╲‾‾‾‾‾╯                      ╲     │
  50,000┤ ‾‾‾‾‾‾‾‾╯                                      ┤   0%
        └┬────────┬────────┬────────┬────────┬────────┬─┘
        2021     2022     2023     2024     2025     2026
  ─ 잔고    ╌ 수익률                        ╌╌ 미수집
```

001의 결측 렌더링 규칙을 잇는다 — **휴장일은 선을 잇고, 시세를 아직 받지 못한 구간은
끊는다**(FR-034).

## W4. 일자별 투자 성과 표

```
  날짜         시작가    주당 배당금  배당율  구매  보유  예수금  투자금   잔고      투자 수익  수익율
  ─────────────────────────────────────────────────────────────────────────────────────────────
  2024-08-01  201,500                        0     1    6,274  86,997  201,500   120,777   138.83%
  2024-07-01  233,500                        0     1    6,274  86,997  233,500   152,777   175.61%
  2024-06-27  229,500      300      0.13%    0     1    6,274  86,997  229,500   148,777   171.01%  ← 배당락
  2024-06-03  189,500                        0     1    6,020  86,997  189,500   108,523   124.74%
  ...
  ─────────────────────────────────────────────────────────────────────────────────────────────
              2021-08-02까지 모두 표시했습니다
```

**행이 두 종류다**(FR-025) — 월 첫 거래일 스냅샷과 배당락일. 배당락 행은 **재투자까지
반영된 상태**를 보인다(FR-027).

**월 행의 배당 칸은 비어 있다**(FR-026). 0을 쓰면 "배당이 0원"과 "배당이 없음"을 구별할
수 없다.

**날짜는 실제 거래일이다**(FR-028). "2024년 8월"이 아니라 "2024-08-01"이다.

**스크롤로 이어 본다**(FR-029). `더 보기` 버튼을 두지 않는다 — 004가 세운 방식이다.
끝에 도달하면 그 사실을 알린다(FR-030). 알리지 않으면 사용자는 아직 받는 중이라고 여겨
기다린다.

### 외화 종목의 환율 열

```
  날짜         시작가(USD)  …  잔고(KRW)    환율      
  ─────────────────────────────────────────────────
  2024-08-01   218.80       …  1,437,900   1,338.50
  2024-07-01   210.62    📅  …  1,401,200   1,340.10  ← 07-01 고시 없음 → 06-28 환율
```

**어느 날짜의 환율을 썼는지 드러난다**(FR-041c). 주식 거래일과 환율 고시일은 일치하지
않는다 — 해외 증시가 열린 날이 국내 휴일일 수 있다.

기호만으로 전달하지 않는다. 004의 `PeriodRowBadges`와 같은 규칙이다.

## W5. 최근 시뮬레이션 (이력)

```
  최근 시뮬레이션                                    ⓘ 이 브라우저에만 저장됩니다
  ┌──────────────────────────────────────────────────────────────────┐
  │ ☑ 삼성전자    2021-08-01  86,997 KRW  재투자 O   +138.83%   [×] │
  │ ☑ Apple       2021-08-01  86,997 KRW  재투자 O   +212.40%   [×] │
  │ ☐ 삼성전자    2021-08-01  86,997 KRW  재투자 X   +121.05%   [×] │
  └──────────────────────────────────────────────────────────────────┘
                                                    [ 선택 항목 비교 ]
```

**각 항목에 종목·시작일·원금·재투자 여부가 함께 남는다**(FR-036). 종목명만 남으면 같은
종목의 다른 조건을 구분할 수 없다 — 위 목록의 1행과 3행이 그 경우다.

**이 브라우저에만 저장된다는 사실을 알린다**(FR-037a). 알리지 않으면 사용자는 계정에
딸린 기록으로 여겨, 다른 기기에서 열었을 때 사라진 것으로 오해한다.

**항목마다 지우는 수단을 둔다**(FR-037b). 지울 수 없으면 쌓이기만 하고, 보관 한계에
닿았을 때 시스템이 임의로 버리게 된다.

## W6. 비교 차트

```
  수익률 비교
  +250%┤                                        ╱‾‾ Apple
       │                                  ╱‾‾‾‾╯
  +150%┤                        ╱‾╲╱‾‾‾‾‾╯    ╱‾‾ 삼성전자
       │              ╱‾‾‾╲‾‾‾‾╯        ╱‾‾‾‾╯
    0%┤━━━━━━━━━━━━━╯                                    
       └┬────────┬────────┬────────┬────────┬───────────┘
       2021     2022     2023     2024     2025
  ※ 모두 KRW 원금 기준 수익률입니다
```

**수익률(%)로 겹친다**(FR-039). 통화가 다른 종목의 잔고를 같은 축에 놓으면 숫자 크기가
달라 한쪽이 평평해지고, 사용자는 그 종목이 움직이지 않았다고 읽는다.

**기준을 밝힌다.** 수익률이 원금 통화 기준이므로(FR-041), 원금 통화가 같은 항목은 그대로
겹칠 수 있다. 다르면 그 사실이 드러나야 한다.

**시작일이 다르면 각 항목의 시작 시점이 드러난다**(FR-040). 위 그림처럼 선이 시작하는
지점이 다르면 눈으로 알 수 있지만, 범례에도 시작일을 적는다.

## W7. 수집 진행

```
  ┌────────────────────────────────────────────────────────┐
  │  삼성전자의 시세를 받고 있습니다                          │
  │  ████████████░░░░░░░░░  2021-08 ~ 2023-04 / 2024-12     │
  │                                                        │
  │  완료되면 결과가 표시됩니다.                              │
  └────────────────────────────────────────────────────────┘
```

**부분 결과를 보여주지 않는다**(FR-049). 받은 만큼만 계산한 수익률은 값이 멀쩡해 보이지만
틀린 값이며, 사용자는 그것을 최종 결과로 읽는다.

**같은 종목의 수집이 진행 중이면 새로 시작하지 않고 이 화면을 보인다**(FR-048).

003이 만든 관측 화면(`/fx/collection`)을 주식으로 확장하지 않는다. 주식 수집 진행은 이
화면 안에서만 보인다.

## 접근성

- 검색 결과 목록은 키보드로 이동·선택할 수 있어야 하고, 현재 강조 항목이 보조 기술에
  읽혀야 한다.
- 수익·손실을 **색만으로 구별하지 않는다.** 부호(`+`/`−`)를 함께 쓴다.
- 환율이 옮겨진 행의 표시는 기호만으로 전달하지 않는다. 텍스트 대체를 둔다
  (004의 `PeriodRowBadges`와 같은 규칙).
- 수집 진행과 표의 이어 보기 상태는 알림 역할이므로 화면에 나타날 때 스크린 리더가
  알린다.
- 비교 차트는 색만으로 계열을 구별하지 않는다. 범례에 종목명과 시작일을 함께 쓴다.

## 갱신 범위

| 조작 | 표 | 보드 | 차트 | 이력 |
|------|-----|------|------|------|
| 시뮬레이션 실행 | 새로 받음 | 갱신 | 갱신 | 항목 추가 |
| 표 이어 보기 | 끝에 덧붙임 | 갱신 없음 | 갱신 없음 | 갱신 없음 |
| 설정 변경 | **새로 받음** | **갱신** | **갱신** | 갱신 없음 |
| 이력 항목 선택 | 갱신 없음 | 갱신 없음 | 갱신 없음 | 선택 표시 |
| 비교 실행 | 갱신 없음 | 갱신 없음 | 비교 차트 | 갱신 없음 |

**설정 변경이 표·보드·차트를 모두 새로 받게 하는 것**이 이 표의 핵심이다(FR-017).
갱신하지 않으면 화면은 정상으로 보이면서 낡은 값을 보여준다.
