# UI 계약: 가격 선·차트 위 상자·표와 이력 배치·주식 다시 실행

**Feature**: `010-chart-price-overlay-history-layout` | **Date**: 2026-10-05

화면 순서는 지금과 같다 — 입력 → 보드 → 안내 → **성과 추이 차트(F1·F2)** → **[성과 표 | 최근 시뮬레이션](F3)** → 이력 비교 차트(전체 폭) → 출처 줄.
주식·가상자산·예금·부동산 네 화면이 같은 부품(`PerformanceChart`, `TableWithHistory`)을 쓴다. 외환 화면은 바뀌지 않는다.

## F1. 성과 추이 차트 — 가격 선 (FR-001~FR-008)

```text
┌ 성과 추이 ───────────────────────────────────────────────────────────────┐
│ 잔고 축(왼쪽)                                              수익률 축(오른쪽) │
│ ₩16,000,000 ┤            ╱──── 잔고 (회색 실선)                   ┤ 60.00 │
│             │      ╱────╱     ╌╌╌ 수익률 (주황 점선)               │       │
│             │ ────╱  ─────●────── 주가 (파랑 실선, 눈금 없음)      │       │
│ ₩10,000,000 ┤╱      ╱      (반복 1: 분할 날에도 이어진다 — 표식 없음) ┤  0.00 │
│             └──────┬───────┬──────────────┬──────────────────────┘       │
│                  2020-03  2020-09        2021-03                          │
│ ─ 잔고 (KRW)  ╌ 수익률 (%)  ─ 주가 (USD)                  95개 전부 표시 │
└──────────────────────────────────────────────────────────────────────────┘
```

- 가격 선은 **세 번째 선**이고 눈금(축)이 없다 — 자기 비율로 차트 높이를 쓴다(FR-004). 잔고·수익률 축과 그 쉼표 형식은 지금 그대로다.
- 범례(`data-testid="chart-legend"`)에 가격 선 이름과 단위를 더한다(FR-005):

  | 화면 | 범례 |
  |------|------|
  | 주식 | `─ 주가 (USD)` — 종목 통화, 분할만 반영한 수정 종가(반복 1 — 분할 표식·`● 분할` 없음). 점은 표의 행 날짜(달 첫 거래일·배당락일 — 일별 아님) |
  | 가상자산 | `─ 시세 (USD)` — 시세 통화 |
  | 예금 | `─ 금리 (연 %)` |
  | 부동산 | `─ 실거래가 평균 (KRW)` — 달마다 점 |

- 끊김(FR-003): 주식 휴장은 잇는다. 가상자산 출처 결측·부동산 시세 없음은 세 선이 함께 끊긴다(지금처럼). 예금 미발표·결측 달과 부동산 거래 없는 달은
  **가격 선만** 끊긴다(잔고·수익률은 그 달에도 값이 있다). 앞뒤 점을 잇지 않고 직전 값을 끌어오지 않는다.
- 결측 구간(출처 결측·시세 없음)마다 시간 축에 빈자리 하나가 생긴다 — 그 자리에 커서를 두면 구간과 사유가 뜬다(research R10-8). 지금은 접혀 있어 커서로
  사유를 볼 수 없다.
- 잠정 구간(`provisionalFrom` 뒤)은 가격 선도 연한 파랑이다(FR-006). 부동산 추정 표식(속 빈 원)은 평가액 선에만 있다.
- 점 하나뿐인 가격 구간은 점으로 보인다(선은 두 점이 있어야 보인다).

## F2. 차트 위 상자 (FR-009~FR-014)

```text
            │        ╱─────
            │   ╱───●  ┌──────────────────────────┐
            │──╱    ┆  │ 2020-09-01               │
            │       ┆  │ 주가(수정 종가) $134.18  │
            │       ┆  │ 잔고    ₩15,342,210      │
            │       ┆  │ 수익률  53.42%           │
            │       ┆  └──────────────────────────┘
```

- 커서 오른쪽 아래 12px에 뜬다. 오른쪽이 넘치면 커서 왼쪽, 아래가 넘치면 위 — 차트 칸 밖으로 잘리지 않는다(FR-012). `data-testid="performance-hover"`,
  `role="tooltip"`.
- 커서가 차트를 벗어나면 사라진다. 차트 아래의 한 줄 표시(`performance-tooltip`)는 없다(FR-013).
- 줄(FR-009, 형식은 표와 같다 — data-model 4절):

  | 화면 | 상자 |
  |------|------|
  | 주식 | 날짜 · 주가(수정 종가) `$134.18`(국내 `₩70,000.00`) · 잔고 `₩…` · 수익률 — 반복 1: 분할 문구 없음 |
  | 가상자산 | 날짜 · 시세 `$0.0000053` · 잔고 `₩…` · 수익률 |
  | 예금 | 날짜 · 잔고 `₩…` · 수익률 · 금리 `연 3.71%` |
  | 부동산 | `2023-06`(첫 점·끝 점은 날짜) · 평가액 `₩…` · 투자 수익 `₩…` · 수익률 · 실거래가 평균 `₩…` |

- 값이 없는 칸(FR-011) — 0이 아니라 "—"와 사유:

  | 경우 | 상자 |
  |------|------|
  | 예금 미발표 달 | 금리 `— 미발표` |
  | 예금 결측 달 | 금리 `— 결측` |
  | 부동산 거래 없는 달 | 실거래가 평균 `— 거래 없음` (평가액·투자 수익·수익률은 적용 시세로 그대로) |
  | 부동산 시세 없음 구간(빈자리) | 구간 `2023-01 ~ 2023-05` · 평가액·투자 수익·수익률·실거래가 평균 모두 `—`, 사유 `시세 없음` |
  | 가상자산 출처 결측 구간(빈자리) | 구간 `2024-03-02 ~ 2024-03-03` · 시세·잔고·수익률 모두 `—`, 사유 `출처 결측` |

- 터치(FR-014): 길게 누르면 십자선이 손가락을 따라가고 같은 상자가 뜬다. 다음 탭에 사라진다(라이브러리 기본 추적 모드).

## F3. 성과 표와 최근 시뮬레이션 (FR-015~FR-017)

넓은 창(두 칸의 고유 폭 합이 본문 폭 이하):

```text
┌ 일자별 투자 성과 ───────────────────────────────┐ ┌ 최근 시뮬레이션 ──────────┐
│ 날짜 │ 구분 │ 시작가 │ … (모든 열 — 잘리지 않음) │ │ ⓘ 이 브라우저에만 저장…   │
│ …                                               │ │ ☐ AAPL · 2020-01-02 …    │
│ …                                               │ │   [다시 실행] [삭제]       │
│ … (아래로 길다)                                  │ │ ☐ …                       │
│                                                 │ │ [선택 항목 비교]           │
│                                                 │ └───────────────────────────┘
│                                                 │   ↑ 표를 내려도 화면 위쪽에 붙어 남는다(sticky)
└─────────────────────────────────────────────────┘
┌ 이력 비교 (전체 폭 — 지금과 같다) ───────────────────────────────────────────────┐
```

좁은 창(합이 본문 폭보다 크다) — 지금과 같다:

```text
┌ 일자별 투자 성과 (전체 폭) ──────────────────────────────────────────────────────┐
└──────────────────────────────────────────────────────────────────────────────────┘
┌ 최근 시뮬레이션 (전체 폭) ───────────────────────────────────────────────────────┐
└──────────────────────────────────────────────────────────────────────────────────┘
┌ 이력 비교 (전체 폭) ─────────────────────────────────────────────────────────────┐
```

- 경계 폭은 상수가 아니라 **그 표의 실제 폭**으로 정해진다(research R10-10). 측정값(plan 표 — quickstart가 다시 잰다): 주식 약 1,800px(원화 원금 해외 종목,
  국내 종목은 더 좁은 창에서도 나란히), 가상자산 약 1,570px, 예금 1,440px 이하, 부동산 약 1,560px. 모두 1920px 이하(SC-004).
- 이력 칸은 400px부터 남는 폭까지(표 바로 오른쪽에 붙는다 — T036 실측으로 고침). 이력이 길면 칸 안에서 세로 스크롤(높이 = 화면 높이 − 2rem). 행은 줄바꿈한다 — 칸 안 가로 넘침이 없다.
- 좁은 창에서도 이력 칸은 최대 높이와 안쪽 스크롤을 가진다(지금과 다른 점) — 한 규칙으로 두 배치를 처리한다(미디어 쿼리 없음).
- 실행 전(표가 없을 때)은 이력만 전체 폭이다. 이력이 비면 "아직 실행한 시뮬레이션이 없습니다"(지금 문구).
- 표의 열은 어느 창 폭에서도 나란히 두기 때문에 줄지 않는다 — 1440px 창 기준(006 FR-069 등)은 지금과 같다.

## F4. 주식 최근 시뮬레이션의 다시 실행 (FR-018~FR-020)

```text
│ ☐ Apple Inc. AAPL · 2020-01-02 · 10,000,000 KRW · 재투자    [다시 실행] × │
│ ☐ 토요타 7203 · 2021-01-04 · 5,000 EUR · 재투자                            │
│   막힌 조합 — 원금은 원화 또는 JPY                           [다시 실행] × │
```

- 행마다 "다시 실행" 버튼 — 가상자산·예금·부동산과 같은 문구·자리(삭제 `×` 앞). `aria-label="{행 이름} 다시 실행"`(가상자산과 같은 꼴). 칸이 좁으면 버튼
  묶음이 다음 줄로 내려간다(F3 — 행 줄바꿈).
- 누르면: 종목이 고른 상태가 되고(검색 칸과 등록 요청을 거치지 않는다 — 이력의 종목은 이미 등록되어 있다) 시작일·원금·원금 통화·배당 재투자가 입력 칸에 들어간 뒤 곧바로
  실행한다.
- 막힌 조합 항목(⚠)도 버튼이 있다 — 누르면 조건이 들어가고 지금 규칙의 거절과 사유가 보인다(FR-019). 통화를 바꿔 실행하지 않는다.
- 아직 받지 않은 구간이면 직접 실행과 같은 수집 진행이 보이고 끝나면 결과가 나온다(FR-020). 종목이 DB에 없으면(DB를 새로 만든 뒤) 직접 실행과 같은 서버 사유가 보인다.

## 접근성

- 상자는 `role="tooltip"`이고 마우스·터치로 연다. 키보드로 점을 옮기는 기능은 범위 밖이다(spec Assumptions — 지금도 없다). 같은 값은 표에 있다.
- 다시 실행 버튼은 키보드로 누를 수 있다(`button`).
- 가격 선의 색만으로 구별하지 않는다 — 범례가 이름·단위를 글로 밝힌다.

## F5. 이름에서 외부 시세 페이지 (반복 1 — FR-024~FR-026)

```text
주식    ┌ 종목 검색 ─────────────┐
        │ 엔비디아                │   ← 검색 목록 항목을 누르면 지금처럼 고르기
        └─────────────────────────┘
        엔비디아(NVDA)↗ NASDAQ · USD      ← 이름이 링크 — 새 탭 stock.naver.com/worldstock/stock/NVDA.O/price

이력 행  ☐ 엔비디아↗ 2020-01-02 10,000,000 KRW 재투자 O   [다시 실행] ×
                 ↑ 링크만 새 탭 — 행 고르기·다시 실행은 일어나지 않는다

가상자산  비트코인 BTC↗          → stock.naver.com/crypto/UPBIT/BTC/price
부동산    보드의 "헬리오시티 · 30평대(국평)" 중 단지 이름↗ → 네이버 검색 "가락동 헬리오시티아파트" — 맨 위 카드가 네이버 부동산 단지 화면
```

- 링크는 `<a target="_blank" rel="noopener noreferrer">`이고 밑줄·바깥 화살표 아이콘으로 바깥 페이지임을 밝힌다. `aria-label`은 `{이름} 네이버 증권에서 보기`
  (부동산은 `네이버에서 단지 찾기`)
- URL 규칙은 data-model 7절·research R10-14·R10-15. 확인하지 못한 시장은 링크가 없다(이름만)

## F6. 외환 화면 (반복 1 — FR-022·FR-023)

- 제목 "외환 데이터 분석"과 본문이 다른 네 화면처럼 왼쪽에서 시작한다(가운데 정렬 없음). 폭 제한은 남긴다(R10-17)
- 통화 탭(USD·JPY·EUR)을 바꾸면 요약·차트·일자별 표가 새 통화로 바뀌고 **창은 움직이지 않는다**
- 일자별 표의 기간 단위(일·주·월)를 바꾸거나 먼 날짜를 고르면 지금처럼 표의 처음으로 간다(004 FR-005b)
