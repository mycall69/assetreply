# UI 계약: 014 대시보드

화면은 서버 문자열에 형식만 입힌다:
- 지수·원자재·VIX: 소수 둘째 자리 + 천 단위 쉼표(`formatRate`)
- 환율: 소수 둘째 자리 + 천 단위 쉼표
- 등락률: `formatPercent`(비율 → %, 부호, 천 단위 쉼표 — 013 FR-021)

색: 오르면 `text-red-700`, 내리면 `text-blue-700`, 변화 없음은 회색(013 비교 표와 같다). 색만으로 구별하지 않는다(▲·▼·부호).

## D1. 대시보드 `/dashboard`

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 대시보드                                                                    │
│ 2026년 10월 9일 (금)  · 한국 시간                       [새로고침] 13:12 받음 │
├──────────────────────────────────────────────────────────────────────────┤
│ 한국                                                                       │
│ ┌ KOSPI ───────────────┐ ┌ KOSDAQ ──────────────┐                         │
│ │ 6,625.93  포인트       │ │ 1,012.40  포인트       │                         │
│ │ ▼ 177.97   −2.62%     │ │ ▲ 3.10   +0.31%       │                         │
│ │ 휴장 · 10-08 종가       │ │ 휴장 · 10-08 종가       │                         │

├──────────────────────────────────────────────────────────────────────────┤

│ │ 22:12 받음                │ │ Latest News · 22:12 받음 │ │ ヘッドライン · 22:12 받음 │ │

```

- 날짜는 늘 한국 시간이다. 한국 자정을 넘기면 바뀐다(R14-15)
- [새로고침]은 지표 시세를 곧바로 다시 부른다(서버 캐시 30초 안이면 같은 값이다). 뉴스는 다시 부르지 않는다(10분 캐시 — 칸마다 [다시 시도])
- 카드는 `button`이 아니라 **링크**(`<a href="/dashboard/{id}">`)다. 접근 이름은 "{이름} 추이 보기"다
- 카드 묶음의 차례는 `order` 그대로다
- 뉴스 칸은 넓은 창에서 셋이 나란하고, 좁으면 아래로 쌓인다(flex-wrap — 경계 상수 없음, 010 관례)
- 카드는 뉴스를 기다리지 않는다 — 뉴스 칸은 따로 받는 중이 보인다

## D2. 카드의 상태

| 상태 | 값 줄 | 상태 줄 | 비고 |
|------|-------|---------|------|
| 장중 | `5,812.34` | `장중 ⏳ 잠정 · 14:28 (한국 14:28)` | 지연이면 `· 약 10분 지연` |
| 점심 휴장 | 오전 장 마지막 값 | `점심 휴장 ⏳ 잠정 · 11:30` | 도쿄·홍콩·상해 |
| 개장 전 | 지난 거래일 종가 | `개장 전 · 10-08 종가` | |
| 마감(오늘) | 오늘 종가 | `마감 ⏳ 확정 전 · 16:00 (한국 05:00)` | 현지 날짜가 지나면 ⏳가 빠진다 |
| 휴장 | 마지막 거래일 종가 | `휴장 · 10-08 종가` | 차이는 그 날과 그 전 거래일의 차이 — 0%가 아니다 |
| 전일 = 출처 | | `전일 값: 출처(이력에 아직 없음)` | `previous.from = "source"` |
| 시장 환율 | | `시장 환율 — 매매기준율과 다를 수 있음 · 전일: 런던 0시 기준` | `market_fx` |
| 선물 | | `선물 근월물 연속` | `future_roll` |
| 새로 받지 못함 | 마지막 성공 값(흐리지 않음) | `새로 받지 못함 · {기준 시각}` + [다시 시도] | `stale: true` |
| 실패(값 없음) | `—` | 까닭 + [다시 시도] | `status: "failed"` |
| 등락률 없음 | `▼ 52.44` / `—` | 등락률 칸에 "직전 값이 0 이하" 설명(`title`) | 음수 가격 |

기준 시각은 그 시장의 현지 시각과 한국 시각을 함께 보인다(한국 시장은 하나). 휴장·개장 전은 날짜만 보인다.

## D3. 지표 화면 `/dashboard/{id}?unit=…`

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ← 대시보드로                                                                │
│ S&P 500 · 포인트 · 미국(뉴욕)                                                │
│ 7,765.36  ▼ 36.41  −0.47%   마감 ⏳ 확정 전 · 16:00 (한국 05:00) · 전일 10-07   │
│ 저장된 기간 1927-12-30 ~ 2026-10-08 · 출처 Yahoo Finance · 마지막 수집 13:30      │
│ (실패가 있으면) 최근 이어 받기 실패 — 출처 응답 제한(429) · 14:00 [다시 시도]       │
│                                                                            │
│ [ 일 ] [ 주 ] [ 월 ] [ 년 ]          (선택된 단추 aria-pressed="true")          │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │                                                         ╱╲   ╱·(⏳)   │ │
│ │                                         ╱╲╱╲╱╲╱‾‾╲╱╲╱╲╱  ╲╱        │ │
│ │  ____________________________╱‾‾╲__╱                               │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│ 커서 상자: 2026-09-30 📅(옮김)  7,702.11                                     │
│ 범례: ─ 확정  ┄ 잠정 · 끊긴 곳은 출처 결측                                      │
└──────────────────────────────────────────────────────────────────────────┘
```

- 머리의 값은 대시보드와 **같은 스토어·같은 경로**(A1)다
- 단위 단추는 주소의 `unit`을 바꾼다(`router.replace`, 스크롤 유지)
- 처음 범위: 일 = 마지막 1년, 주 = 5년, 월 = 20년, 년 = 전체. 끌기·확대로 전체를 본다
- 잠정 점(오늘·끝나지 않은 기간·외환 잠정)은 연한 색이다. 커서 상자는 `⏳ 잠정`·`⏳ 끝나지 않은 구간`·`📅 옮김`을 보인다
- 선물: 머리에 "선물 근월물 연속 — 만기 교체로 끊김이 있을 수 있음"
- 환율: 머리에 "ECOS 매매기준율 — 카드의 시장 환율과 다른 계열" — 머리 값(시장 환율)과 그래프(고시)가 다른 계열임을 나란히 보인다
- `tailPending`: 머리에 "최근 구간 받는 중"
- `history.lastFailure`: 그래프는 그대로 두고 머리에 "최근 이어 받기 실패 — {까닭} · {시각}" + [다시 시도](A3)

## D4. 지표 화면 — 받는 중 · 실패 · 없는 지표

```
받는 중:  S&P 500 이력을 받는 중입니다 — 2010-01-04 ~ 2026-10-08 받음 (첫 날 1927-12-30) [진행 막대]
실패:     이력을 받지 못했습니다 — 출처 응답 제한(429) · 13:05   [다시 시도]
없는 지표: 없는 지표입니다: "kospii"   [대시보드로]
```

- 받는 중에는 그래프를 그리지 않는다 — 받은 만큼만 그린 선을 보이지 않는다(FR-016)
- 진행 스트림의 `completed`가 오면 그래프로 바뀐다. 새로고침이 필요 없다

## D5. 뉴스 칸의 상태

| 상태 | 칸 |
|------|----|
| 받는 중 | "받는 중…" |
| 성공 | 머리: 나라·출처 이름(출처 화면 링크, 새 탭)·목록 이름·받은 시각. 줄: 차례, 제목(링크), 언론사, 시각, `유료` |
| 실패 | "받지 못했습니다 — {까닭}" + [다시 시도](`retryAfterSeconds`가 남았으면 "n초 뒤 다시 시도할 수 있습니다") |
| 0건 읽기 | "읽지 못함 — 출처 화면이 바뀌었을 수 있음" + [다시 시도] |

- 기사 링크: `<a href={url} target="_blank" rel="noopener noreferrer">`
- 시각:
  - `publishedAt`이면 한국 시간 `HH:mm`(오늘이 아니면 `MM-DD HH:mm`)
  - `publishedDate`면 `MM-DD`
  - `publishedText`면 글자 그대로

## D6. 사이드바·상단 바

- 사이드바 "대시보드" → `/dashboard`. "준비중" 표시를 없앤다
- `/dashboard`와 `/dashboard/*`에서 "대시보드"만 선택된 상태다
- 상단 바 제목은 `/dashboard*`에서 "대시보드"다
- 최상위 `/`는 `/dashboard`로 옮긴다
