# Contract: UI 스케치

**Feature**: 001-fx-rate-history | **Date**: 2026-08-30

화면의 **정보 구조와 상태별 배치**를 확정한다. 색상·타이포그래피·간격 같은 시각 디자인은
포함하지 않는다. 각 스케치는 [rest-api.md](./rest-api.md)의 응답 형태와 1:1로 대응한다.

상호작용 규칙은 [ui-chart.md](./ui-chart.md), 진행률 스트림은 [sse-progress.md](./sse-progress.md) 참조.

---

## S1. 환율 조회 — 고시가 있는 날 (FR-016, FR-020, FR-022)

`GET /api/fx/rates/{currency}` → `status: "quoted"`

```text
┌────────────────────────────────────────────────────────────────────────┐
│  통화  (●) USD   ( ) JPY   ( ) EUR        날짜  [ 2005-03-15  ▦ ]      │
│                                                          [ 조회 ]      │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   USD  2005-03-15                                                      │
│                                                                        │
│   매매기준율                                          1,012.30 원      │
│   ───────────────────────────────────────────────────────────────      │
│                                                                        │
│   현금 살 때        1,014.12 원         송금 보낼 때    1,012.81 원    │
│   현금 팔 때        1,010.48 원         송금 받을 때    1,011.79 원    │
│                                                                        │
│   ┌──────────────────────────────────────────────────────────────┐    │
│   │ ⓘ 현재 설정된 스프레드를 이 날짜에 적용한 결과입니다.          │    │
│   │   현금 0.18% · 송금 0.05%                    [ 스프레드 변경 ] │    │
│   └──────────────────────────────────────────────────────────────┘    │
│                                                                        │
│   출처: 한국은행 ECOS (731Y001)                                        │
└────────────────────────────────────────────────────────────────────────┘
```

**설계 근거**
- 매매기준율을 파생 환율보다 위·크게 배치한다. 파생값은 가정이 섞인 값이고 매매기준율만이 출처 값이다.
- `appliedSpread`를 항상 노출하고 `spreadBasis: "current"`를 문장으로 설명한다 (FR-026a).
  이 문구가 빠지면 사용자는 2005년 당시 실제 스프레드로 오해한다.

### JPY 선택 시 — 고시 단위 표기 (FR-007)

```text
│   JPY  2020-06-15                                                      │
│                                                                        │
│   매매기준율                                    1,102.45 원 / 100엔    │
│   ───────────────────────────────────────────────────────────────      │
│   현금 살 때   1,104.66 원/100엔    송금 보낼 때  1,103.11 원/100엔    │
```

단위를 값 옆에 붙여, USD와 같은 축의 수치로 오인되지 않게 한다.

## S2. 환율 조회 — 고시가 없는 날 (FR-018, FR-018a, FR-018b)

`status: "no_quote"`

```text
┌────────────────────────────────────────────────────────────────────────┐
│  통화  (●) USD   ( ) JPY   ( ) EUR        날짜  [ 2005-03-19  ▦ ]      │
│                                                          [ 조회 ]      │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   USD  2005-03-19 (토)                                                 │
│                                                                        │
│        해당일에는 고시가 없습니다.                                     │
│                                                                        │
│                                                                        │
│  ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌ 참고 정보 ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌     │
│                                                                        │
│   ┌──────────────────────────────────────────────────────────────┐    │
│   │  직전 영업일  2005-03-18 (금)                                 │    │
│   │  매매기준율                                     1,010.90 원   │    │
│   │                                                               │    │
│   │  ⚠ 요청하신 2005-03-19의 값이 아닙니다.                       │    │
│   │                                    [ 2005-03-18로 조회 ]      │    │
│   └──────────────────────────────────────────────────────────────┘    │
└────────────────────────────────────────────────────────────────────────┘
```

**설계 근거 — 이 화면이 헌법 원칙 V를 지키는 방식**
- 주 결과 영역에는 **숫자가 없다**. "고시 없음"이 답이다.
- 참고 값은 점선 구분선 아래 별도 박스 안에만 존재하며, 박스 안에서도 날짜를 먼저 보여준다.
- 파생 환율 4종을 참고 영역에 표시하지 **않는다**. 요청일의 값이 아닌데 4종까지 나열하면
  S1과 시각적으로 구별되지 않는다.
- 값을 쓰려면 명시적으로 그 날짜로 다시 조회하게 한다.

```text
                    └─────────────────────┘
```

### 결측 구간 위 툴팁 (FR-032, FR-032b)

```text
       ┌──────────────────────────┐        ┌──────────────────────────┐
       │ 2020-01-24 ~ 01-27       │        │ 2026-08-01 ~ 08-29       │
       │ 고시 없음 (휴장)          │        │ 아직 수집되지 않음        │
       └──────────────────────────┘        └──────────────────────────┘
```

**설계 근거**
- 하단에 다운샘플링 사실과 원본 개수를 명시한다. 사용자가 보는 것이 전수가 아님을 숨기지 않는다.
- 결측 구간은 선을 끊고 범례로 두 종류를 구분한다. Lightweight Charts는 포인트 사이를 기본적으로
  직선 연결하므로 시리즈 분리가 필요하다 (ui-chart.md).
- 툴팁 날짜는 **실제 포인트의 날짜**다. 포인터 위치의 날짜가 아니다.

## S4. 수집 진행 중 (FR-008, FR-034, FR-035a)

조회·차트가 임계값 초과 수집을 유발했을 때, 결과 영역을 대체한다.

```text
┌────────────────────────────────────────────────────────────────────────┐
│   USD 환율을 수집하고 있습니다.                                        │
│                                                                        │
│   ████████████████████░░░░░░░░░░░░░░░░░░░░░░░░  36 / 63 구간           │
│                                                                        │
│   현재 구간   2013-01-01 ~ 2013-12-31                                  │
│   수집 완료   1964-01-01 ~ 2000-12-31                                  │
│                                                                        │
│   완료되면 요청하신 2005-03-15의 결과가 자동으로 표시됩니다.           │
│                                                                        │
│                                              [ 수집 현황 자세히 보기 ] │
└────────────────────────────────────────────────────────────────────────┘
```

### 중단된 경우 (FR-013, FR-007)

```text
│   ⚠ 수집이 중단되었습니다.                                             │
│                                                                        │
│   사유   호출 한도 초과(INFO-300)가 반복되어 중단했습니다.             │
│   진행   36 / 63 구간 완료                                             │
│                                                                        │
│   1964-01-01 ~ 2000-12-31 구간은 정상적으로 저장되어 조회할 수 있습니다.│
│                                                     [ 다시 시도 ]      │
└────────────────────────────────────────────────────────────────────────┘
```

**설계 근거**: 중단 화면이 "이미 저장된 구간은 유효하다"를 반드시 말해야 한다 (FR-013).
이 문장이 없으면 사용자는 전부 실패한 것으로 판단하고 처음부터 다시 돌린다.

```text
│  USD   [-0.1    ]◀ 0 이상 1 미만이어야 합니다                          │
```

## S6. 수집 현황 (FR-004, FR-037, FR-038a)

```text
┌────────────────────────────────────────────────────────────────────────┐
│  수집 커버리지                                          [ 지금 수집 ]  │
│                                                                        │
│  통화   수집 완료 구간                  최초 제공일    마지막 갱신      │
│  USD    1964-01-01 ~ 2026-08-29        1964-05-04    08-30 01:12      │
│  JPY    1977-01-01 ~ 2012-12-31 ⚠      1977-04-01    08-30 00:19      │
│  EUR    1994-01-01 ~ 2026-08-29        1994-04-11    08-30 01:15      │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│  최근 수집 작업                              [전체 ▾] [실패만] [진행중] │
│                                                                        │
│  통화  상태      구간                     진행     종료                │
│  JPY   부분성공  1977-01-01~2026-08-29   36/50   08-30 00:19          │
│        └ 호출 한도 초과(INFO-300)가 반복되어 중단했습니다.             │
│  USD   성공      1964-01-01~2026-08-29   63/63   08-30 01:12          │
│  EUR   성공      1994-01-01~2026-08-29   33/33   08-30 01:15          │
└────────────────────────────────────────────────────────────────────────┘
```

**설계 근거**
- 통화마다 최초 제공일이 다른 경우를 스케치에 반영했다(USD 1964 / JPY 1977 / EUR 1994).
  최초 제공일은 런타임에 발견되므로(research R3) 특정 연도를 전제하는 UI는 틀린다.
  "수집 완료 구간"(탐색 시작일 기준)과 "최초 제공일"(발견된 값)은 다른 값이며 둘 다 보여준다.
- 실패 사유를 목록 안에 펼쳐 보여준다. 별도 화면으로 숨기면 SC-011(사후 확인)의 목적이 흐려진다.

## 상태 매핑 요약

| 화면 상태 | API 응답 | 관련 요구사항 |
|-----------|----------|---------------|
| S1 결과 표시 | `200` `quoted` | FR-016, FR-020, FR-022 |
| S2 고시 없음 | `200` `no_quote` | FR-018, FR-018a, FR-018b |
| S4 수집 중 | `202` `collecting` + SSE `progress` | FR-035a, FR-034 |
| S4 중단 | SSE `completed` (`partial`/`failed`) | FR-013 |
| 범위 밖 안내 | `400` `out_of_range` | FR-019 |
| S5 입력 거부 | `422` `invalid_spread` | FR-025 |
| 출처 한도 안내 | `503` `source_rate_limited` | FR-013 |
