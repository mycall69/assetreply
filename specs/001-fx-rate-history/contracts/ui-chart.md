# Contract: 차트 UI 상호작용

**Feature**: 001-fx-rate-history | **Date**: 2026-08-30

FR-029, FR-030, FR-031을 충족한다. 데이터 계약은 [rest-api.md](./rest-api.md)의
`GET /api/fx/series`를 참조한다.

## 기간 선택 (FR-029, FR-013)

프리셋과 직접 지정 두 방식을 제공한다.

| 프리셋 | 구간 |
|--------|------|
| 1개월 | 오늘 − 1개월 ~ 어제 |
| 1년 | 오늘 − 1년 ~ 어제 |
| 5년 | 오늘 − 5년 ~ 어제 |
| 전체 | 해당 통화의 `firstAvailableDate` ~ 어제 |

직접 지정은 시작일·종료일을 입력받는다. 종료일이 어제를 넘으면 어제로 절단하고 그 사실을 표시한다
(FR-002는 축적 범위를 어제까지로 규정한다).

"전체" 선택 시 미수집 구간이 임계값을 초과하면 차트 대신 진행 상태를 표시한다 (FR-032a).

## 시점 가리키기 (FR-030)

포인터가 차트 위에 있을 때 해당 시점의 **날짜**와 **매매기준율**을 표시한다.

- 표시 값은 서버가 준 `points`의 원본 값이다. 클라이언트에서 보간하지 않는다 (헌법 원칙 V).
- 다운샘플링으로 제외된 날짜 위에 포인터가 놓이면, 가장 가까운 **실제 포인트**의 날짜를 표시한다.
  요청한 날짜를 표시하고 다른 날의 값을 보여주어서는 안 된다.
- `gaps` 구간 위에서는 값 대신 결측 사유(`no_quote` / `not_collected`)를 표시한다.
- JPY는 값과 함께 `quoteUnit`(100엔당)을 표시한다 (FR-007).

## 상세 조회로 이동 (FR-031)

차트에서 한 시점을 선택하면 그 날짜의 상세 조회 결과로 이동한다.

- 이동 대상 날짜는 표시 중이던 **실제 포인트의 날짜**다.
- 이동 후 `GET /api/fx/rates/{currency}?date=...`의 결과를 표시한다. 그 날짜가 고시 없는 날이면
  상세 화면은 `no_quote` 응답 규약을 그대로 따른다 (FR-018a).

## 결측 구간 렌더링 (FR-032, FR-032b)

**`reason`에 따라 다르게 그린다.** `gaps`가 둘을 구분해 내려주는 이유가 이것이다.

| `reason` | 뜻 | 선 | 범례 |
|----------|-----|-----|------|
| `no_quote` | 커버리지 안인데 값이 없음 = **휴장일·주말** | **잇는다** | 표시하지 않는다 |
| `not_collected` | 커버리지 밖 = **아직 수집 안 함** | **끊는다** | `╌╌ 미수집 N구간` |

**휴장일을 잇는 이유**: 그날은 시장이 열리지 않아 값이 존재하지 않는다. 실제로 존재하는 두
고시일 사이를 잇는 것은 값을 만들어내는 것이 아니며, 세계의 환율 차트가 금요일과 월요일을
잇는 것과 같다. 반대로 휴장일마다 끊으면 1년 보기에서 50구간 넘게 쪼개져 추세가 읽히지 않는다.

**미수집을 끊는 이유**: 값이 존재할 수 있는데 받지 않은 것이다. 이으면 **구멍 위에 온전한 선**이
그려져 사용자가 데이터를 다 가졌다고 믿는다. 헌법 원칙 V가 막으려는 것이 이쪽이다.

Lightweight Charts는 데이터 포인트 사이를 기본적으로 직선 연결하므로, **끊으려면** 시리즈를
분리하거나 `whitespace` 처리를 해야 한다. 잇는 쪽은 아무것도 하지 않으면 된다.

**툴팁 규칙은 그대로다** — 결측일 위에서는 값 대신 결측 사유를 보여준다(위 §툴팁). 선을 잇는
것과 값이 있다고 말하는 것은 다르다.

## 성능 (FR-033, SC-006)

- 서버가 `maxPoints`로 다운샘플링하므로 클라이언트가 받는 포인트는 기본 2,000개 이하다.
- 확대·이동·값 확인 조작은 1초 이내에 반응해야 한다.
- 확대 시 더 조밀한 데이터가 필요하면 좁아진 구간으로 `GET /api/fx/series`를 다시 호출한다.
