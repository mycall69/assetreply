# UI 와이어프레임 — 화면별 정보 구조와 상태 배치

**Feature**: 002-fx-analysis-workspace | **Date**: 2026-08-30

이 문서는 **정보의 배치와 상태별 표현**을 고정한다. 색상·간격·타이포그래피 같은 시각 디테일은
구현 단계에서 정한다. 스케치의 목적은 "무엇이 어디에, 어떤 상태로 보이는가"에 대한 합의다.

---

## W1. 전역 셸 (FR-001~005, FR-049)

```text
┌──────────────────────┬───────────────────────────────────────────────────────┐
│  ▣ AssetReplay       │  외환                              ◉ 수집 중 (USD)   │
│  Professional Sim.   ├───────────────────────────────────────────────────────┤
│                      │                                                       │
│  ▤ 대시보드   준비중 │                                                       │
│ ┃▧ 외환              │              (선택된 화면의 본문)                     │
│  ▤ 주식       준비중 │                                                       │
│  ▤ 가상자산   준비중 │                                                       │
│  ▤ 예금       준비중 │                                                       │
│  ▤ 부동산     준비중 │                                                       │
│  ▤ 투자 비교  준비중 │                                                       │
│  ⚙ 설정              │                                                       │
│                      │                                                       │
└──────────────────────┴───────────────────────────────────────────────────────┘
```

**규칙**

- `┃`는 현재 위치의 좌측 강조 바다. 배경색과 함께 쓴다 — 색 하나에만 의존하지 않는다(FR-003).
- "준비중" 항목은 **링크가 아니다.** 클릭 대상이 아니며 라우트도 존재하지 않는다(FR-005,
  research R2-9). 키보드 포커스 순서에서도 제외한다.
- 상단 우측 `◉ 수집 중`은 수집이 진행 중일 때만 나타난다(FR-049). 클릭하면 수집 현황
  (`/fx/collection`)으로 이동한다. 진행 중이 아니면 이 자리는 비어 있다.
- 상단 좌측에는 현재 화면 이름을 둔다(FR-004).

**왜 "준비중"을 배지로 두는가**: 메뉴를 아예 숨기면 제품의 방향을 알 수 없고, 활성처럼 보이게
두면 클릭했을 때 빈 화면에 도달한다. 배지는 "있지만 아직 아니다"를 한 눈에 말한다.

**규칙**

- **요약의 큰 숫자**는 오늘 잠정값이 있으면 그것, 없으면 마지막 확정값이다(FR-011). 어느
  쪽인지를 `⚠ 잠정` 배지와 기준 날짜로 밝힌다(FR-014).
- 변화량은 방향 기호(`▼`/`▲`)와 색을 **함께** 쓴다(FR-013). 색만으로 구분하지 않는다.
- **차트의 세로 실선(`┃`)과 표의 좌측 바(`┃`)와 날짜 입력**은 같은 선택 날짜를 가리킨다
  (FR-008, FR-009). 어느 하나를 바꾸면 나머지 둘이 따라온다.
- 차트 우측 끝 `╌╌`는 잠정 구간이다. 확정 구간(`─`)과 선 스타일로 구분하고 범례에 밝힌다
  (FR-017a).
- 표에서 **2026-08-16 ~ 08-28이 없는 것이 정상**이다. 고시가 없는 날은 행을 만들지 않는다
  (FR-021). 날짜가 연속하지 않는다고 결함이 아니다.
- 표 하단 문구는 파생 4종이 가정임을 밝힌다(FR-024). 표에서 유일하게 실측인 열은 매매기준율뿐이다.
- `⟳ 새로고침`은 오늘 하루치만 다시 받는다(FR-036). 마지막 갱신 시각을 요약에 표시한다(FR-038).

## W3. 외환 화면 — 상태별 변화

### W3-a. 선택 날짜에 고시가 없을 때 (FR-018, FR-022)

```text
│ 특정일 검색 / 하이라이트                                                     │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ 📅 2026-08-16                                                            │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
│ ⓘ 2026-08-16은 고시가 없는 날입니다 (주말·공휴일).                          │
│   직전 영업일 2026-08-15의 매매기준율은 1,368.50입니다.                     │
```

차트에서는 강조선을 그리되 **곡선과 만나는 점 표식을 두지 않는다.** 값을 가리키지 않는다는
사실이 그 자체로 드러난다. 표에는 강조할 행이 없으므로 위 안내가 그 공백을 설명한다.

### W3-b. 오늘 고시가 아직 없을 때 (FR-039)

```text
│ 매매기준율 (USD/KRW)                                          ⟳ 새로고침    │
│                                                                             │
│  1,356.10   ▼ -3.70 (-0.27%)                                                │
│  확정 · 2026-08-29 기준                                                     │
│  ⓘ 오늘 고시는 아직 없습니다. 14:23에 확인했습니다.                        │
```

큰 숫자는 마지막 확정값이다. 오늘 값을 만들어내지 않는다.

### W3-c. 새로고침 실패 (FR-040)

```text
│  1,354.20   ▼ -2.00 (-0.15%)                                                │
│  ⚠ 잠정 · 2026-08-30 14:23 기준                                            │
│  ⚠ 새로고침에 실패했습니다 (데이터 제공처 응답 없음). 위 값은 14:23 기준입니다.│
```

**이미 표시 중인 값을 지우지 않는다.** 실패했다고 화면을 비우면 사용자는 가진 정보까지 잃는다.

### W3-d. 데이터가 전혀 없을 때

```text
│                     아직 수집된 환율 데이터가 없습니다.                     │
│           전 구간을 처음 수집하는 데 몇 분이 걸립니다.                      │
│              통화에 따라 60년치가 넘습니다.                                 │
│                          [ 수집 시작 ]                                      │
```

### W3-e. 선택 날짜가 표의 표시 범위 밖일 때 (FR-022a)

```text
│ 일자별 환율 상세                                              ⤓ 내려받기  │
│ ┌───────────────────────────────────────────────────────────────────────┐ │
│ ┃ 2019-03-14    1,132.40   1,134.44   1,130.36   1,132.97   1,131.83   ┃ │
│ │ 2019-03-13    1,130.20   1,132.23   1,128.17   1,130.77   1,129.63   │ │
│ │  ⋮                                                                    │ │
│ └───────────────────────────────────────────────────────────────────────┘ │
│  ⓘ 차트에서 선택한 2019-03-14 기준으로 표를 옮겼습니다.  [ 최근으로 ]     │
```

선택 날짜가 첫 행이 되고, 최근으로 돌아갈 수단을 함께 제공한다. 표가 조용히 과거로 옮겨가면
사용자는 무슨 일이 일어났는지 알 수 없다. 이 경우가 선택 날짜 변경이 서버를 부르는 **유일한
예외**다(contracts/ui-interaction 갱신 범위 표).

## W4. 설정 — 외화 스프레드 (FR-027~035)

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│  설정                                                                         │
├───────────────────────────────────────────────────────────────────────────────┤
│  외화 스프레드                                          [ 전체 기본값 복원 ] │
│                                                                               │
│  ⓘ 여기서 정한 값이 모든 과거 날짜에 동일하게 적용됩니다. 시점별 이력은      │
│    관리하지 않습니다 — 과거에 실제로 적용됐던 스프레드는 알 수 없습니다.     │
│                                                                               │
│  ┌─────────────────────────────────────────────────────────────────────────┐ │
│  │ USD (미국 달러)                          기본값과 다름  [ 기본값 복원 ] │ │
│  │   현금 살 때   [ 0.002500 ]  ← 기본값 0.001800                          │ │
│  │   현금 팔 때   [ 0.001800 ]                                             │ │
│  │   송금 보낼 때 [ 0.000500 ]                                             │ │
│  │   송금 받을 때 [ 0.000500 ]                                             │ │
│  ├─────────────────────────────────────────────────────────────────────────┤ │
│  │ JPY (일본 엔)                                                           │ │
│  │   현금 살 때   [ 1.500000 ]                                             │ │
│  │   ⚠ 0 이상 1 미만이어야 합니다. 저장되지 않았습니다.                    │ │
│  │   현금 팔 때   [ 0.002000 ]                                             │ │
│  │   ⋮                                                                     │ │
│  ├─────────────────────────────────────────────────────────────────────────┤ │
│  │ EUR (유로)                                                              │ │
│  │   ⋮                                                                     │ │
│  └─────────────────────────────────────────────────────────────────────────┘ │
│                                                       [ 취소 ]  [ 저장 ]     │
└───────────────────────────────────────────────────────────────────────────────┘
```

**규칙**

- 통화 순서는 항상 **USD → JPY → EUR**이다(FR-027). 정렬 옵션을 두지 않는다.
- 범위 위반은 **해당 입력 바로 아래**에서 알린다(FR-029). 상단에 모아 보여주면 어느 칸이
  문제인지 찾아야 한다.
- 기본값과 다른 통화에는 "기본값과 다름" 표시와 함께 원래 값을 보여준다(FR-033).
- 복원 버튼이 두 층위에 있다 — 통화별과 전체. 어느 범위인지가 버튼 문구에서 드러난다(FR-032).

### W4-a. 복원 확인 (FR-032)

```text

        │  USD 스프레드를 기본값으로 되돌립니다               │
        │                                                     │
        │    현금 살 때    0.002500  →  0.001800              │
        │    현금 팔 때    0.001800  →  0.001800  (변화 없음) │
        │    송금 보낼 때  0.000500  →  0.000500  (변화 없음) │
        │    송금 받을 때  0.000500  →  0.000500  (변화 없음) │
        │                                                     │
        │  현재 입력값은 사라집니다.                          │
        │                        [ 취소 ]  [ 되돌리기 ]       │
        └─────────────────────────────────────────────────────┘
```

**무엇이 어떻게 바뀌는지를 먼저 보여준다.** "정말 하시겠습니까?"만 묻는 확인창은 사용자가
결과를 모른 채 누르게 한다.

## W5. 수집 현황 (`/fx/collection`)

001의 화면을 그대로 옮긴다. 진입 경로만 바뀐다 — 사이드바 메뉴가 아니라 **셸 상단의
`◉ 수집 중` 표시기**를 통해 들어온다(research R2-10).

레이아웃은 [001 ui-sketches.md](../../001-fx-rate-history/contracts/ui-sketches.md) S6을 따른다.

**001 대비 추가되는 것 하나** — 잠정 잔존 경고 (FR-043a).

```text
│  통화   수집 완료 구간                  최초 제공일    마지막 갱신      │
│  USD ⚠  1964-01-01 ~ 2026-09-08        1964-05-04    09-09 01:12      │
│         ⚠ 2026-09-05의 값이 아직 확정되지 않았습니다.                  │
│           이 통화의 수집을 실행하면 해소됩니다.                        │
│  JPY    1977-01-01 ~ 2026-09-08        1977-04-01    09-09 01:15      │
│  EUR    1994-01-01 ~ 2026-09-08        1994-04-11    09-09 01:18      │
```

**규칙**

- 오늘 날짜의 잠정은 **정상 상태이므로 표시하지 않는다**(FR-043b). 표시하면 매일 경고가
  떠 신호로서 쓸모가 없어진다.
- 통화 열의 `⚠`와 아래 문장을 **함께** 쓴다. 색 하나에 의존하지 않는다.
- 경고에는 해소 방법(해당 통화의 수집 실행)이 반드시 포함된다. 원인만 알려주는 경고는
  운영자가 할 수 있는 일이 없다.
- 잔존이 여러 날 있으면 **가장 오래된 날짜**를 보여준다. 어제부터 남은 것과 열흘 전부터
  남은 것은 심각도가 다르다.

## 접근성 최소 요건

명세에 별도 요구가 없으나, 위 스케치가 전제하는 최소선을 적어 둔다.

- 상승·하락은 색과 **방향 기호를 함께** 쓴다(FR-013). 색 하나로 의미를 전달하지 않는다.
- 잠정 상태는 색이 아니라 **배지 문구(`⚠ 잠정`)**로 표시한다. 차트에서는 선 스타일로 구분하고
  범례에 명시한다.
- "준비중" 메뉴는 키보드 포커스 순서에서 제외한다. 포커스는 갔는데 아무 일도 일어나지 않는
  상태가 가장 혼란스럽다.
- 표의 선택 행은 배경색과 좌측 바를 함께 쓴다.
